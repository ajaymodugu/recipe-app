# recipe-app
The app shows the recipes of North America countries, you can filter based on type and cooking time, serves etc 

# Recipe App
Full-stack app: React frontend, Spring Boot API, MySQL DB from JSON recipes.

## Setup
1. Run database/schema.sql in MySQL.
2. Backend: cd backend, mvn spring-boot:run (populates DB first run).
3. Frontend: cd frontend, npm start.
4. API: http://localhost:8080/api/recipes
